# Evaluacion2 - Geolocalización con Python y Graphhopper

Este repositorio contiene la solución mejorada del software de geolocalización desarrollado en Python dentro del entorno DEVASC.

## Requerimientos Cumplidos
1. **Traducción total al español:** Interfaz, mensajes e instrucciones en español.
2. **Formato numérico:** Todos los valores flotantes (distancia, tiempo, coordenadas) limitados a 2 decimales (`:.2f`).
3. **Opción de salida:** Cierre del programa con `s` o `salir`.
4. **Narrativa en español:** Instrucciones paso a paso obtenidas mediante la API REST de Graphhopper en español.

## Instrucciones de Uso
1. Ejecute en la terminal:
   python3 script_evaluacion2.py
2. Seleccione el vehículo (`auto`, `bicicleta`, `pie`).
3. Ingrese el origen y el destino.
4. Para terminar el programa en cualquier momento, escriba `s` o `salir`.
